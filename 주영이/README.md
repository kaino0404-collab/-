# 주영이

가족 사진·영상 갤러리 앱 (Flask 기반, PyInstaller로 빌드된 실행 파일)

## 포함된 것
- `주영이.exe` — 완성된 실행 파일. 실행하면 로컬에 웹서버(기본 포트 8731)가 뜨고 브라우저로 접속해 사용합니다.

## 실행 시 자동 생성되는 것 (이 저장소엔 포함하지 않음)
실행 폴더에 `_주영이_data/` 폴더가 자동으로 만들어지며 아래 내용을 담습니다. 개인정보·저작권·용량 문제로 저장소에는 올리지 않았습니다.

- `data.db` — 사진/영상 메타데이터 인덱스 (개인 데이터)
- `secret.key` — 앱 내부 인증/암호화 키 (절대 공개 저장소에 올리면 안 되는 비밀 값)
- `thumbs/` — 사진·영상 썸네일 캐시 (개인 사진에서 파생된 이미지)
- `log.txt` — 서버 접속 로그
- `bin/` — 서드파티 도구 (용량 문제로 미포함, 필요 시 아래에서 직접 받아서 `_주영이_data/bin/`에 넣으면 됩니다)
  - [ffmpeg](https://ffmpeg.org/download.html), [ffprobe](https://ffmpeg.org/download.html) — 영상 썸네일·재생 정보 추출용
  - [cloudflared](https://github.com/cloudflare/cloudflared/releases) — 외부(핸드폰 등)에서 원격 접속할 때 사용하는 터널링 도구 (선택 사항)

## 원본 사진·영상
개인 미디어 파일 자체는 이 저장소에 포함되지 않습니다. 실행 파일과 같은 위치에 원하는 폴더를 두고 앱에서 스캔하도록 사용하세요.
